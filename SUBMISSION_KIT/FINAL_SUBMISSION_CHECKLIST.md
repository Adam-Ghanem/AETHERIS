# Submission package checklist

This ZIP contains **source code and supporting material**. A ZIP alone is not automatically an official completed submission: upload the required project information and links to the official portal according to the portal's actual instructions.

- [ ] Application starts on a clean Windows machine with supported Python.
- [ ] NASA POWER request verified on your internet connection.
- [ ] Research Campaign Studio retrieves authentic observations and exports real evidence.
- [ ] All sources are credited; no synthetic test data presented as empirical findings.
- [ ] Public code repository created and actual URL entered in project form.
- [ ] Demo URL or recorded video uploaded, if required by the submission form.
- [ ] Short project description and detailed description adapted from `PROJECT_SUBMISSION_TEXT.md`.
- [ ] Team and contributor names and roles correctly entered.
- [ ] Screenshots reflect actual app and disclose any synthetic fixtures.
- [ ] Link to an accessible demo or instructions for local installation.
- [ ] Video or live pitch includes data source, statistical limitations, user journey and impact.
- [ ] Source code release excludes secrets, tokens, private files and `.env` credentials.
- [ ] External ML functionality described as optional unless genuinely connected and tested.

**Files to share:** application repository (or this ZIP if accepted), `PROJECT_SUBMISSION_TEXT.md`, a real demo video/link, and optionally the offline project pitch. The offline campaign presentation can be exported from the running app after a genuine investigation.
